# Future Plan: Markdown preview toggle in file viewer

## Intent
Добавить в док-панель предпросмотра переключатель для файлов `.md`: показывать либо исходный текст, либо уже интерпретированный (отрендеренный) Markdown — чтобы документация репозитория читалась прямо в плагине без внешнего просмотрщика.

## In scope
- Определение markdown-файла по расширению `.md`
- Переключатель режимов «исходник / предпросмотр» в шапке док-панели, видимый только для markdown-файлов
- Рендер Markdown на клиенте: заголовки, списки, ссылки, код-блоки, таблицы, изображения из воркспейса (при доступности)
- Запоминание выбранного режима в localStorage в рамках воркспейса
- Тема рендера на DSH-токенах с поддержкой светлой/тёмной темы

## Out of scope
- Редактирование Markdown (WYSIWYG, live-редактор)
- Рендер других лёгких разметок (AsciiDoc, reStructuredText и т.п.)
- Рендер Markdown в других местах UI (дерево, диффы)

## Absorbs into
- Living canon: Architecture (Key flows — предпросмотр файла, UI), Overview (Scope)

## Open questions
- Рендерить на клиенте (библиотека Markdown) или на сервере (возвращать HTML)?
- Как встраивать изображения из воркспейса в рендер с учётом границ доступа?
- Поведение с усечёнными файлами (> 5 МБ): рендерить частично или отключать?
