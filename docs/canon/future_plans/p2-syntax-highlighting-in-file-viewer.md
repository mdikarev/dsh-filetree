# Future Plan: Syntax highlighting in file viewer

## Intent
Добавить подсветку синтаксиса для языков программирования в док-панели предпросмотра текстовых файлов, чтобы чтение и ревью кода в плагине файлового менеджера не требовали открытия внешнего редактора.

## In scope
- Определение языка по расширению файла (с запасными эвристиками: имя файла, первая строка/shebang)
- Подсветка базовых токенов — ключевые слова, строки, комментарии, числа, операторы
- Языки первого релиза: TypeScript, JavaScript, Python, Go, C#, Rust
- Тема подсветки на DSH-токенах с поддержкой светлой/тёмной темы
- Деградация: файл без распознанного языка остаётся моноширинным текстом без подсветки

## Out of scope
- Редактирование кода и IDE-функции (автодополнение, навигация по символам)
- Линтинг, форматирование и статический анализ
- Подсветка синтаксиса в других местах UI (дерево, диффы)
- Языки вне списка первого релиза (C/C++, Java, JSON/YAML, Markdown и др.) — добавляются позднее

## Absorbs into
- Living canon: Architecture (Key flows — предпросмотр файла, UI), Overview (Scope)

## Open questions
- Где выполнять токенизацию: на клиенте (библиотека подсветки) или на сервере (возвращать размеченные токены)?
- Как вести себя с усечёнными файлами (> 5 МБ): подсвечивать частично или отключать подсветку?
- Стратегия производительности для больших файлов (виртуализация/дебаунс токенизации)?
