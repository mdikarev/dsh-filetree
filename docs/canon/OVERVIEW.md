# Overview

## Purpose
Плагин файлового менеджера дает быстрый доступ к дереву файлов текущего воркспейса и просмотр содержимого текстовых файлов, изображений и форматированного JSON. Вкладка-ручка у сайдбара открывает панель-шторку (300px) с деревом каталогов: папки раскрываются лениво, показываются git-статусы, клик по файлу открывает док-панель предпросмотра;
раскрытые каталоги автоматически отражают изменения на диске через SSE с polling fallback, а изменение текущего preview-файла требует явного подтверждения.

## Problem & context
Пользователям часто нужно заглянуть в содержимое файла (код, конфигурации, документацию) не покидая текущий контекст. Просмотр во всплывающей док-панели снижает трение: не требует переключения вкладок и остается поверх интерфейса.

## Primary users / agents
- Пользователи DeepSeek Harness Web GUI
- Агентные плагины, которые опираются на визуальный просмотр

## Scope

### In scope
- Панель дерева: вкладка-ручка `▶`/`◀`, шторка 300px слева, ленивое раскрытие папок, сохранение раскрытых путей по воркспейсу, кнопки ↻ и ✕
- Git-статусы на строках: бейджи `M`/`A`/`D`/`?`/`I` для файлов, `•` для папок, приглушённый тон для ignored
- Просмотр ТЕКСТОВЫХ файлов во всплывающей док-панели с клиентской подсветкой highlight.js для TypeScript, JavaScript, Python, Go, C# и Rust
- Определение языка предпросмотра по расширению/имени файла и shebang; неизвестный язык показывается как обычный моноширинный текст
- Ограничение размера считанного содержимого: до 5 МБ, с признаком усечения; усечённые файлы и файлы сверх поддерживаемого лимита остаются обычным текстом
- Клиентский Markdown preview для `.md` без учёта регистра: переключение режимов «Исходник»/«Предпросмотр», с режимом «Исходник» по умолчанию и сохранением выбора в localStorage отдельно для каждого воркспейса
- Безопасный Markdown-рендер: HTML и опасные URL-схемы не исполняются; относительные ссылки и изображения ограничены текущим воркспейсом; безопасные локальные относительные изображения рендерятся инлайн через capability-URL `/filemanager-fs/raw`, внешние текстовые ссылки открываются в новой вкладке, внешние изображения блокируются
- Просмотр — док-панель справа от панели дерева: шапка с названием файла и кнопкой закрытия; окно перетаскивается за шапку по экрану, с возможностью ресайза; прокручиваемое тело
- Превью изображений из дерева (png/jpeg/gif/webp/avif/svg) в той же док-панели: вписывание по размеру + зум кнопками тулбара и двойным кликом (100%/fit, clamp 0.1–8×); колесо мыши не перехватывается (зум колесом отсутствует); натуральные размеры в тулбаре, «открыть оригинал в новой вкладке»; svg-ответы отдаются с `content-security-policy: sandbox`
- JSON pretty-view для `.json`: переключатель Raw/Formatted (по умолчанию Formatted для валидного JSON до 1 МБ) с подсветкой highlight.js (язык json); невалидный/слишком большой JSON показывается как raw-текст с локализованной пометкой
- Сервер изображений: `GET /filemanager-fs/cap` (header-гейт, per-workspace capability-токен, TTL 8 ч, ротация) и `GET /filemanager-fs/raw` (единственный эндпоинт без header — авторизация cap; magic-byte определение типа; лимиты 20 МБ raster / 2 МБ svg; `no-store`/`nosniff`)
- Безопасность путей: чтение только внутри корня воркспейса
- Живое обновление дерева: серверный `fs.watch` только на раскрытые каталоги (и корень `""`), SSE-подписка `GET /filemanager-fs/events?hint=<ws>&paths=<url-encoded JSON array>` с обязательным header `x-dsh-filemanager: 1`, нормализованный payload `{ type: "changed", path, kind }`, debounce 250 мс и targeted invalidation только затронутых раскрытых узлов; git-бейджи обновляются по событию `git-changed` при изменении git-метаданных (`index`/`HEAD`/`refs`), ручной ↻ не требуется
- Надёжность живого обновления: серверный кэш git-статуса (TTL 2 с + инвалидация событиями — burst-листинги делят один прогон git), SSE-heartbeat `event: ping` раз в 10 с и клиентский inactivity-watchdog (30 с тишины → polling со статус-баннером)
- Локализация UI: английский по умолчанию, русский сохраняется (авто для ru-браузеров, оверрайд `fm-locale`); доступность L1 (роли дерева/aria, полная клавиатура, Esc закрывает предпросмотр, focus-visible); тултип полного имени для обрезанных строк дерева
- Polling fallback раскрытых каталогов раз в 5 секунд при недоступности SSE/watcher, reconnect с backoff (500 мс → кап 10 с) и остановка polling при восстановлении SSE
- Confirmation banner при изменении текущего preview-файла на диске: «Обновить» / «Оставить текущую версию», без молчаливой перезагрузки содержимого
- Перенос файлов и папок из дерева в поле ввода чата (drag-and-drop): строки дерева перетаскиваемы; дроп на композер вставляет DSH-упоминание пути — `@path` для файлов, `@path/` для папок, `@"path"` при пробелах — в позицию каретки через input machine (`conversation.input`); пути с управляющими символами или кавычками не вставляются; дроп с OS-файлами и чужими типами данных не затрагивается

- Удаление файлов и папок через контекстное меню строки дерева (правый клик или Menu/Shift+F10): single-объект (файл целиком или папка рекурсивно); инлайн-диалог подтверждения с полным путём; предупреждение о незакоммиченных изменениях git (modified/added/untracked, для папок — по содержимому; ignored не считаются); symlink удаляется как ссылка (цель не затрагивается); корень воркспейса и любой сегмент `.git` защищены (403); после успеха списки обновляются через live refresh, раскрытые пути prune-ются, открытый preview удалённого файла закрывается; ошибки (403/404/409) показываются в панели

### Out of scope
- Просмотр произвольных бинарных форматов (PDF, видео, документы), редактирование изображений, тумбнейлы изображений в дереве, `.jsonc`/YAML pretty и сворачиваемый JSON
- Редактирование и сохранение файлов (кроме явного подтверждённого удаления); прочие мутации (create/rename/move/copy); корзина/undo/восстановление; мультивыбор-удаление; удаление через drag-and-drop
- Операции за пределами воркспейса
- Наблюдение всего workspace при закрытых каталогах; двусторонние WebSocket-команды; молчаливое (без подтверждения) обновление preview
- Перенос из OS-проводника (браузер не раскрывает абсолютные пути, только содержимое); мультивыбор строк дерева; вставка чипами-карточками (всегда текстовое упоминание `@path`)

## Success signals
- Вкладка `▶` открывает панель дерева, `◀` закрывает; папки раскрываются лениво; раскрытое состояние сохраняется между сессиями в рамках воркспейса
- Git-статусы видны на строках дерева (бейджи и тона)
- Клик по файлу открывает док-панель с содержимым; шапка показывает имя; есть кнопка ✕ для закрытия
- Окно панели можно менять по размеру и перетаскивать за шапку; длинный контент прокручивается
- Позиция и размер панели запоминаются в рамках воркспейса и восстанавливаются при следующем открытии
- Серверный endpoint `/filemanager-fs/read` возвращает JSON с `content` и `truncated`; для файлов >5 МБ контент усечен, `truncated: true`
- Подсветка в предпросмотре выполняется на клиенте через highlight.js; стили токенов используют DSH-токены в светлой и тёмной темах
- highlight.js относит распространённые ключевые слова, включая `if`/`export`/`const`, к общему классу `hljs-keyword`, поэтому они намеренно используют один акцентный цвет; более тонкое семантическое различение категорий ключевых слов не входит в текущую реализацию
- При ошибке подсветки или невозможности определить язык панель сохраняет исходный моноширинный текст; для бинарных/не-текстовых файлов возвращается понятная ошибка и панель показывает сообщение
- Для Markdown переключатель виден только у `.md`; ошибка renderer-а показывается в панели, но исходный текст остаётся доступен, а `truncated: true` показывает доступное начало с заметным предупреждением и не считается ошибкой
- Раскрытый каталог отражает создание/удаление/rename на диске после debounce (~250 мс); закрытые каталоги не опрашиваются и не инвалидируются; события из `.git` не доставляются
- Изменённый на диске preview-файл показывает confirmation banner «Файл изменён на диске» и обновляется только по явному «Обновить»; «Оставить текущую версию» скрывает баннер до следующего события
- При сбое SSE включается polling (статус-баннер «Автообновление: опрос каталогов»), после восстановления SSE polling останавливается; watcher-ы, EventSource и таймеры освобождаются при disconnect/закрытии панели, ручной ↻ продолжает работать
- Строку дерева можно перетащить в поле ввода: при дропе в область композера в позицию каретки вставляется `@path` (файл) / `@path/` (папка) / `@"path with spaces"`; дроп мимо композера или с чужими типами данных ничего не вставляет; путь с запрещёнными символами пропускается
- UI-копия переключается между en (default) и ru; дерево обходится клавиатурой (стрелки/Home/End/Enter/Space/ArrowLeft/Right), превью закрывается по Escape; у обрезанного имени при наведении показывается полный тултип
- Клик по изображению в дереве открывает док с fit/зумом и «открыть оригинал»; безопасные локальные относительные картинки в `.md` рендерятся, внешние блокируются
- JSON `.json` по умолчанию показывается форматированным (валидный, < 1 МБ); невалидный/слишком большой — raw с пометкой; выбор Raw/Formatted сохраняется per-workspace
- `/cap` выдаёт токен только с header; `/raw` отдаёт изображение только по валидному cap (403/404/415/413 иначе) и с правильными заголовками (no-store/nosniff, CSP sandbox для svg)
