# Overview

## Purpose
Плагин файлового менеджера дает быстрый доступ к дереву файлов текущего воркспейса и просмотр содержимого текстовых файлов. Вкладка-ручка у сайдбара открывает панель-шторку (300px) с деревом каталогов: папки раскрываются лениво, показываются git-статусы, клик по файлу открывает док-панель предпросмотра.

## Problem & context
Пользователям часто нужно заглянуть в содержимое файла (код, конфигурации, документацию) не покидая текущий контекст. Просмотр во всплывающей док-панели снижает трение: не требует переключения вкладок и остается поверх интерфейса.

## Primary users / agents
- Пользователи DeepSeek Harness Web GUI
- Агентные плагины, которые опираются на визуальный просмотр

## Scope

### In scope
- Панель дерева: вкладка-ручка `▶`/`◀`, шторка 300px слева, ленивое раскрытие папок, сохранение раскрытых путей по воркспейсу, кнопки ↻ и ✕
- Git-статусы на строках: бейджи `M`/`A`/`D`/`?`/`I` для файлов, `•` для папок, приглушённый тон для ignored
- Просмотр ТЕКСТОВЫХ файлов во всплывающей док-панели
- Ограничение размера считанного содержимого: до 5 МБ, с признаком усечения
- Просмотр — док-панель справа от панели дерева: шапка с названием файла и кнопкой закрытия; окно перетаскивается за шапку по экрану, с возможностью ресайза; прокручиваемое тело
- Безопасность путей: чтение только внутри корня воркспейса

### Out of scope
- Просмотр изображений и бинарного содержимого (инициатива в future_plans)
- Редактирование файлов, сохранение изменений
- Операции за пределами воркспейса

## Success signals
- Вкладка `▶` открывает панель дерева, `◀` закрывает; папки раскрываются лениво; раскрытое состояние сохраняется между сессиями в рамках воркспейса
- Git-статусы видны на строках дерева (бейджи и тона)
- Клик по файлу открывает док-панель с содержимым; шапка показывает имя; есть кнопка ✕ для закрытия
- Окно панели можно менять по размеру и перетаскивать за шапку; длинный контент прокручивается
- Позиция и размер панели запоминаются в рамках воркспейса и восстанавливаются при следующем открытии
- Серверный endpoint `/filemanager-fs/read` возвращает JSON с `content` и `truncated`; для файлов >5 МБ контент усечен, `truncated: true`
- Для бинарных/не-текстовых файлов возвращается понятная ошибка; панель показывает сообщение
