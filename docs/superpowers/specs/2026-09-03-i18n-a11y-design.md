# i18n (EN default + RU) & Basic Accessibility — Design

**Status:** draft (phase G of the maturity roadmap, 2026-09-03).
**Scope:** (G1) plugin-local minimal i18n — typed en/ru dictionaries with English default, Russian preserved and auto-selected for ru-locale browsers; (G2) basic accessibility — tree semantics + keyboard, preview dialog/Esc, toggle-button semantics, focus-visible styling. Depth L1 (per roadmap).
**Spec for:** docs/superpowers/plans/2026-09-02-maturity-roadmap.md phase G.

## Context / constraints discovered

- DSH client locale ships only zh/en (html lang = zh-CN/en; a ru browser falls back to en). Host-level localization therefore cannot express Russian: the plugin needs its own locale scheme.
- UI copy inventory: ~17 user-facing strings, all in src/Panel.tsx, src/Tree.tsx, src/ToggleTab.tsx (aria-labels included). Server/console messages and git aria-labels are already English and stay untouched.

## Decisions (agreed)

- D1 (i18n): plugin-local mini-i18n (approach A). Not the host locale registry (zh/en only would drop Russian; zh copy not authored).
- D2 (a11y depth): L1 baseline. L2 (aria-selected, focus return), L3 (drag keyboard alternative, live regions) are out of scope.

## Design

### G1 — localization (src/l10n.ts, new)

- Typed dictionaries: en is the source of truth (L10nKey = keyof typeof en); ru: Record<L10nKey, string> compiled with a completeness check; getMessage(locale, key) returns the string (en fallback for safety).
- Keys cover: panel title fallback (Files), refresh, close, open/close panel (ToggleTab titles), empty folder, loading, no workspace, error prefix + retry, live-fallback banner, markdown group aria-label + source/preview mode labels, preview close, changed-on-disk banner text + update/keep-current buttons, preview-unavailable prefix, local-images warning, truncated-file warning. Interpolations (Error: <msg>, Preview unavailable: <msg>) are prefix strings concatenated at call sites.
- Locale resolution: getInitialLocale() = localStorage fm-locale when in {en, ru} else navigator.language (primary subtag) == ru ? ru : en. Pure and injectable for tests (detectLocale(forcedLanguageHint)).
- React wiring: a tiny module store (listeners + getSnapshot) fed by setLocale(locale) (writes localStorage, notifies) and by window storage events (cross-tab); components consume it via useSyncExternalStore; t(key) reads the current snapshot. Switching languages re-renders live.
- Replace the Russian literals in Panel.tsx / Tree.tsx / ToggleTab.tsx with t(...).

### G2 — basic accessibility (L1)

Tree (src/Tree.tsx):

- Container: role="tree" with an aria-label provided by Panel (rootName, fallback localized Files).
- Rows: role="treeitem", aria-level set from the recursion depth (new level prop, root rows = 1); folders carry aria-expanded={expanded}.
- Keyboard: every row is focusable (tabIndex 0 — children render only when expanded, so the DOM row set equals the visible tree). A container-level keydown handler moves focus among the visible .fm-row elements: ArrowUp/ArrowDown prev/next, Home/End first/last (pure helper treeNavStep(currentIndex, visibleCount, key) -> next index, unit-tested). Row-level Enter and Space activate the row action (files open the preview, folders toggle); folders additionally respond to ArrowRight (expand) and ArrowLeft (collapse). preventDefault on Space so the page does not scroll.
- Row mouse behavior (click, drag, hover tooltip) is unchanged.

ToggleTab (src/ToggleTab.tsx):

- The handle div becomes keyboard-accessible: role="button", tabIndex 0, aria-expanded={open}, Enter/Space toggle (same as click). Title strings come from t().

Preview (src/Panel.tsx):

- The window gets role="dialog" and aria-label={previewTitle}.
- Escape closes the preview while it is open (window keydown listener added when previewOpen, removed on close/unmount).

Styles (src/styles.ts):

- focus-visible outlines on .fm-row, .fm-toggle and preview buttons using the DSH brand token (outline: 2px solid var(--dsw-alias-brand-primary); outline-offset: 2px or -2px as fits each element), light and dark safe (token-driven).

### Behavior and compatibility

- Default UI language is English; Russian users (navigator ru) get Russian automatically; manual override via localStorage fm-locale (setLocale) — no settings UI in this phase.
- All existing mouse flows, drag-and-drop, live refresh, tooltips and git badges are unchanged; only semantics/strings/keys added.
- No changes to host contracts, HTTP API, or fs-api shapes.

### Testing

- test/l10n.test.ts (node): dictionary completeness (ru keys == en keys), getMessage fallback, detectLocale (forced ru/en/other/empty), store notify on setLocale.
- test/tree-nav.test.ts or folded into l10n file: treeNavStep boundaries (first/last, wrap decisions, Home/End).
- UI/DOM wiring (roles, focus, Esc) has no DOM harness in this repo — typecheck + manual browser pass (keyboard walk of the tree, Esc closes preview, Tab reaches the toggle and rows) close the loop.
- Gate: npm run typecheck && npm test && npm run build.

## Non-goals (parked)

- L2/L3 a11y (aria-selected/active-file, focus return, live regions, keyboard drag alternative); zh translation; a settings UI for the plugin language; i18n of server/console strings.

## Rollout

Single commit set on main after spec review: l10n module + tests, string replacement, a11y changes, styles, docs (roadmap/CHANGELOG). No contract change; default language changes from Russian to English for non-ru browsers only.
